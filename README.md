# docx-fresh

Give [python-docx](https://github.com/python-openxml/python-docx) documents fresh metadata instead of the default template's.

`docx.Document()` without a template copies the document properties of python-docx's bundled `default.docx`. Every new file says it was written in 2013 by "python-docx" in Word for Mac, and Windows Explorer and Word's **File > Info** show it:

| Property | Without docx-fresh | With docx-fresh |
| --- | --- | --- |
| Author | `python-docx` | empty, or the name you pass |
| Last modified by | empty | same as author |
| Comments | `generated by python-docx` | empty |
| Created / Modified | 2013-12-23 23:15 UTC | now |
| Application (app.xml) | `Microsoft Macintosh Word` 14.0 | not set |
| Pages, words, lines (app.xml) | 1 page, 0 words | not set |
| Thumbnail | the template's | none |

## Install

```
pip install docx-fresh
```

## Use

```python
import docx
from docx_fresh import fresh

document = fresh(docx.Document(), author="Report bot")
document.add_heading("Weekly report", 1)
document.save("report.docx")
```

`fresh()` changes only values that still equal the default template's. A document made from your own template keeps its author, dates, app.xml and thumbnail, so it is safe to call on every document.

Options:

- `author`: written to Author and Last modified by. Default `""`.
- `now`: timezone-aware time for Created and Modified. Default: the current UTC time.

The page, word and line counts are removed rather than recomputed: only the application that lays the document out can count pages, and Word fills them in on its next save.

### Fix existing files

```
docx-fresh report.docx                  # in place
docx-fresh report.docx -o fixed.docx    # to a new file
docx-fresh report.docx --author "Report bot"
```

## Why not fixed in python-docx?

python-docx already sets Modified to now when a package has no document properties at all, but `default.docx` has them, so that code never runs. Until it is fixed upstream, `fresh()` is one line.
